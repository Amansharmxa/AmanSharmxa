### 📊 Featured Project
**[Superstore Sales Data Analysis](https://github.com/amansharma/superstore-sales-data-analysis)**
* **Overview:** Built an end-to-end data analytics project using a retail sales dataset (~9,800 rows).
* **Key Steps:**
  1. **Data Cleaning & Preprocessing (Excel & Python):** Handled missing values, removed duplicates, and fixed date formats.
  2. **Feature Engineering (Python):** Extracted temporal features like `Order_Year`, `Order_Month`, and `Order_DayOfWeek`.
  3. **Database & SQL Querying (PostgreSQL):** Loaded data into a relational database and queried key business metrics (Total Revenue, YoY Growth, Top Customers, Regional Contribution).
  4. **Visualization (Power BI):** Designed an interactive dashboard featuring KPI cards, monthly revenue trends, and yearly sales growth charts.
