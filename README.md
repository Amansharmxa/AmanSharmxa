## 🚀 Featured Project

### 📈 [Superstore Sales Analysis](https://github.com/Amansharmxa/superstore-sales-data-analysis)

An end-to-end analysis of the Kaggle Superstore dataset: **9,800 transactions · 4,922 orders · 793 customers · 2015–2018**.

| Stage | What I did |
|---|---|
| **Excel** | Removed blank rows and columns and stabilised the raw data |
| **Python** (Pandas, Jupyter) | Removed duplicates, handled missing Postal Codes, standardised dates, engineered 3 columns (Year, Month, Weekday) |
| **PostgreSQL** | Wrote 5 queries: KPIs, category and sub-category sales, YoY trend, top 5 customers, regional sales share |
| **Power BI** | Built an interactive dashboard connected to PostgreSQL, with KPI cards, yearly and monthly trends and a year slicer |

**Key insights**

- 💰 **2.26M** total revenue, **459.48** average order value
- 📈 Sales grew by about **50%** from 2015 to 2018
- 🌎 **West** region led with **31.4%** of revenue
- 💻 **Technology** was the top category (**36.6%**)
- 🗓️ Sales peaked in **November**
